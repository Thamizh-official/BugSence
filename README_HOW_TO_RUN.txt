====================================================================
           PREMIUM PORTFOLIO - HOW TO RUN ON ANY PC
====================================================================

NO NODE.JS INSTALLATION NEEDED! (Fully Portable)

HOW TO RUN:
1. Copy the "premium-portfolio" folder anywhere on the other PC (e.g., Desktop or C: drive).
2. Open the folder.
3. Double-click on "LAUNCH.bat".
4. The server will start and automatically open your web browser at:
   http://127.0.0.1:8000

FEATURES:
- Uses self-contained portable Node.js (inside this folder).
- Works 100% offline without internet.
- Works on Windows 10, Windows 11, etc.
